# ST-022 — Leaking Attention

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A content strategist must keep one promise alive to payoff despite every second opens a new topic, because the viewer cannot resolve the first question; the story resolves when the original question reaches an answer.

## Story spine

- Setup: a workshop table
- Inciting change: The bucket changes state before the objective is secure.
- Objective: keep one promise alive to payoff
- Obstacle: every second opens a new topic
- Stakes: the viewer cannot resolve the first question
- Action: notice the bucket → plugs side topics and routes detail to one channel → inspect the sealed channel
- Proof: sealed channel
- Limitation: Curiosity should not become deceptive withholding.
- Payoff: the original question reaches an answer
