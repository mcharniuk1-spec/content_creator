# The 20-question test: does ChatGPT recommend your shop?

Before paying anyone for an "AI visibility audit", spend one hour and do this yourself.

1. Write 20 questions a real customer would type before buying from a shop like yours. Use their words, not yours: "best natural sleep supplement UK", "gift for a ceramics lover under £40", "is [your brand] legit".
2. Type each question into ChatGPT, Gemini and Perplexity. New chat each time. Log: who is named, in which position, and which source the answer cites.
3. Count: how many of 20 name you; how many name each competitor; which pages get cited (yours, a marketplace, a review site).
4. For every question where a competitor is named and you are not, open the cited page and note what it has that yours lacks: a comparison, a spec table, real reviews, a plain answer to that exact question.
5. Link GA4: the "AI" default channel already shows how much traffic arrives from these assistants. Write the number down before you change anything.
6. Fix the top three gaps on your own site (one page each). Re-run the same 20 questions in 30 days.

Log sheet: question · assistant · named? (you / competitor / nobody) · cited page · what it has that we lack.

What you do not need: a $3,000 audit and $400 a month to watch a number you can type in yourself. Pay an agency only if the audit turns into work you cannot do: fixing product data, writing the missing comparison pages, measuring whether it changed sales.
