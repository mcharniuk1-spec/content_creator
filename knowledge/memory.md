# Memory

## Durable constraints

- The first phase is provider-disabled and stops at owner-review-ready research and previsualization.
- Current proved Agent Reach routes are YouTube, RSS, and generic public web only; channel reach is never inferred from tool installation or configuration.
- Sherlock is only a candidate public brand-handle discovery adapter and never proves identity or collects content.
- OpenMontage is a candidate downstream production/editing worker, not the research, governance, knowledge, Figma, or publishing core.
- The owner `content_creator` repository was a README-only placeholder when checked on 2026-08-11.
- Final small typography, captions, charts, and product UI remain editable deterministic layers.
- Figma mutation, provider generation, private media, voice/likeness, publishing, deployment, and Git writeback each require a separate exact approval.
- Existing-video editing uses a canonical reviewed JSON EDL: Codex/AI proposes timecoded decisions, FFmpeg/ffprobe performs deterministic media work, OTIO is optional, Resolve is human finishing, and generative repair is disabled by default.
- Studio short-form previsualization uses a causal story contract: protagonist/POV, objective, obstacle, stakes, observable action, changed state, inspectable proof, explicit limitation, payoff, and A-roll handback. Frame changes must correspond to information, entity-state, or causal changes rather than arbitrary cut frequency.
- The reviewed Studio v2 reference set contains 50 six-second story packages across 10 story families, with 300 one-second SVG frames and machine-readable entity-state and causal contracts. These are deterministic previsualizations, not final footage or performance evidence.
- North Hux social intelligence uses local PostgreSQL as normalized evidence authority, run-local files for raw comments/transcripts/media/frames, Notion as a redacted review projection, and Obsidian as curated method/decision/insight memory. Cohort claims require run-scoped database joins and content-addressed pointer verification; global table totals are insufficient.
- For YouTube, short-duration eligibility and native Shorts placement are separate evidence states. The 2026-08-26 calibration proved 872 duration candidates but zero native Shorts claims.
- YouTube automatic VTT captions can be rolling windows rather than independent speech cues. Preserve the raw cue layer, derive a de-rolled speech layer by exact suffix/prefix token overlap, and run transcript-based coding on the speech layer. In the 2026-08-26 calibration, 73,339 raw cues reduced to 38,960 speech increments; the median raw-to-speech word expansion was 2.91x.
- Search-ranked YouTube candidates are a broad screen, not automatically qualified competitors. The independent 2026-08-26 review accepted 211 of 250 sampled creators/videos (84.4%) as direct agentic-business, technical-agentic authority, or adjacent AI-business relevance; scale estimates must retain this calibrated precision and its uncertainty.
- Studio v3 contains 50 clean-room photorealistic story packages and 300 ordered 540×960 reference frames. Identity, wardrobe, location, light, prop, and direction locks are mandatory; final text/UI remains editable. The imagery is fictional previsualization, not creator imitation, source reconstruction, or performance evidence.
