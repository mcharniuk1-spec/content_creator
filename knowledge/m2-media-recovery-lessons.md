# M2 media recovery lessons

For future Codex: use this note when continuing the existing-corpus media workflow. It describes bounded methods and evidence distinctions; it is not a full-corpus completion receipt, final competitor ranking or proof of production readiness.

FACT (6 September 2026): The actual local pilot retained acquired Reel videos, transcribed with multilingual Faster-Whisper small on CPU int8, and decoded regular plus visual-change frames. The first eight-identity dispatcher tranche passed independent review with limitations for same-run expansion. Its runtime/configuration was frozen before bulk execution. Full-corpus processing remains in progress.

FACT: Michael's cached clip-response method is reused through direct cache parsing. Missing cache entries do not invoke HikerAPI. A separately tested anonymous public resolver supplies an additional route without browser cookies or login. Loore AI is optional and disabled by default; local media work does not depend on it.

FACT: Every identity retains separate acquisition, transcript, frame and scene-review states. An observed ASR artifact is machine evidence, not verified word accuracy. Empty output, invalid timing and missing original audio remain separate uncertainties. A downloaded video-only format does not establish that the original Reel had no speech.

FACT: The corrected three-Reel scene candidates in the original scene-pilot R2 were independently accepted for candidate extraction with limitations. Planned 2/4/6 samples are distinct from extracted sample counts. Frames outside a half-open scene interval must be labelled boundary neighbors and excluded from observed scene coverage. Cut candidates remain technically unconfirmed; neither ASR segments nor abrupt image changes automatically establish semantic scenes.

FACT: Independently reviewed bounded transcript structures preserve exact source segment wording and timestamps. Primary partitions are exclusive and account for each source segment once. Secondary rhetorical spans can overlap but are explicitly non-additive. Uncertain source names and speaker-stated outcomes stay uncertain; structural review is not acoustic or factual verification.

INTERPRETATION: Freeze code, model, configuration and source identities before a bulk run; revalidate artifacts on resume. Preserve the first failure and create source-bound repair evidence. One heavy process, two inference threads, an RSS watchdog, byte/time limits and a storage reserve make recovery controllable. A sampled watchdog is not an OS hard memory cap; pause at storage limits rather than deleting retained source videos.

FACT: A reviewed, isolated five-window local ASR test recovered machine output after one memory-limited chunk succeeded on retry. Four completed windows were reused and prior attempt files retained their hashes. Independent review accepted execution evidence only: the aggregate remained timing-review required and unapproved for acoustic accuracy. This demonstrates bounded recovery and resume behavior on the tested source; it does not establish universal recovery or accurate transcription.

INTERPRETATION: Keep owned aligned words separate from padded chunk sums. Overlapping context makes raw chunk totals non-additive. ASR segment coverage is not measured speaking time, and bracketed music/caption annotations are not verified spoken words. Preserve the original text and counts with explicit quality dispositions instead of silently converting them into speech evidence.

FACT: The video-only fallback retained a source and yielded actual frame samples while preserving unknown original audio and speech. A completed pilot held the primary dispatcher lock, preventing another media worker from starting. Review-receipt bindings include the evidence under review and distinct maker/reviewer identities; an accepted label alone is insufficient for quality promotion.

INTERPRETATION: Use machine-emitted run/database timestamps for chronology. Manually supplied communication times are not authoritative execution evidence. Runtime probes should use the exact lexical virtual-environment launcher; separately bind its resolved binary, package identity and external media tools.

GAP: Whole-corpus coverage, acoustic accuracy, reviewed semantic scenes, final statistical models/cards and an accepted free generation backend are unfinished. Two hosted free smoke attempts produced no usable accepted video. A provider's API availability or a queued request is not reliability evidence. Partner-host setup and authenticated semantic execution remain separate from shipping portable code.
