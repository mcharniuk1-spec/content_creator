# M2 Lab portable knowledge

This directory contains bounded reusable context, not raw founder transcripts or competitor evidence. A file marked candidate remains unreviewed until a distinct reviewer promotes it.

- [[m2-positioning]] — current derived audience, method, pillars, claims and CTA boundaries; read the explicit review status.
- [[m2-operating-memory]] — current state, evidence and production constraints; read the explicit review status.
- [[memory]] — accepted operating boundaries and the promotion route.
- [[insights]] — interpretation/promotion boundary.

The original `POSITIONING.md` at the repository root is retained as source context. The shared executable architecture is in `docs/m2-system-architecture.md`, `docs/m2-operator-guide.md`, `agents/m2-roles.json` and the two role skills. Current source observations, account identities, transcripts, frames, metric releases and owner approvals belong in private frozen runs and the append-only Signal database.

Each substantial run records inputs, output hashes, tests, maker/reviewer, unresolved gaps and the next safe action. Promote reusable conclusions only after independent review, duplicate/conflict search, scope/freshness checks and an explicit source-addressed record. Notion is a review projection. An external Obsidian/WikiLLM sync needs exact target authority and readback; this checkout does not silently write to either system.
