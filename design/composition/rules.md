# Composition rules: five references

These are the rules for where text, numbers, icons and marks sit in a frame. Each rule
below comes from one of five references we borrow **techniques** from, not their look.
This is the owner's selection from 8 September 2026: three references from the earlier
draft (technical report, lab notebook, field guide) were dropped.

---

## 1 · Engineering drawing

Technical drawings made to be read by whoever builds or fixes the thing, not to
be admired.
https://en.wikipedia.org/wiki/Engineering_drawing

- Pull every label outside the object it describes — never set text on top of
  the thing it names.
- Draw a thin leader line ending in a point exactly at the spot it refers to.
- Reserve red exclusively for what is broken or out of tolerance; it carries no
  other meaning anywhere in the frame.

Shows up in: verdict card, data-slide callouts.

## 2 · Isotype

A picture-statistics system that shows quantity by repeating one icon, never by
resizing it.
https://en.wikipedia.org/wiki/Isotype_(picture_language)

- Show quantity by repeating one identical glyph — never scale a single glyph
  up or down to mean "more".
- Use an empty outline to mean "no longer here"; the difference must read
  without a caption.
- Keep every unit glyph the same size, always.

Shows up in: data slide (implementation economics — hours, cost).

## 3 · Swiss grid — International Typographic Style

Mid-century grid typography that carries hierarchy through scale and weight,
never through centring.
https://en.wikipedia.org/wiki/International_Typographic_Style

- Align everything to the left edge; nothing is ever centred.
- **Owner's correction:** set that left edge with a visible indent off the
  guide — not flush against it.
- Lay a four-column grid under the frame; every element snaps to a guide.
- Build hierarchy with size and weight only, never with colour.

Shows up in: carousel slide, lower third.

## 4 · Oscilloscope

A measurement display that marks one point on a trace and never lets a number
stand alone.
https://en.wikipedia.org/wiki/Oscilloscope

- Place a cursor exactly on the point under discussion, label right beside it.
- Always label the axes — a chart without axis labels does not ship.
- Reserve the accent colour for lit data on a dark field, nowhere else.
- Frame every number as WAS / NOW / SAVED — never bare.

Shows up in: data slide, reel-cover metric.

## 5 · Checklist

An operational list where state reads from the shape of each line, not only
its colour.
https://en.wikipedia.org/wiki/Checklist

- Encode state (done / blocked / pending) in the frame's shape, not colour
  alone.
- One line, one item — an item never wraps across two lines.
- Maps directly onto KEEP / KILL / TEST.

Shows up in: verdict card.

---

**If a decision in the frame cannot be traced to one of these five sources, it
is not accepted: justify it or remove it.**
