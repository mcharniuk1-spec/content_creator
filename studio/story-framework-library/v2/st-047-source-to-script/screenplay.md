# ST-047 — Source to Script

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A research writer must convert evidence into original narration despite source wording is too close to the draft, because the script risks imitation; the story resolves when the narration keeps meaning without expression.

## Story spine

- Setup: a writing workstation
- Inciting change: The source page changes state before the objective is secure.
- Objective: convert evidence into original narration
- Obstacle: source wording is too close to the draft
- Stakes: the script risks imitation
- Action: notice the source page → extracts facts, closes the source, then rewrites → inspect the claim notes
- Proof: claim notes
- Limitation: Distinctive examples and metaphors remain excluded.
- Payoff: the narration keeps meaning without expression
