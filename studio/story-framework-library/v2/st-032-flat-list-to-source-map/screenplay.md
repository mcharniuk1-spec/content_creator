# ST-032 — Flat List to Source Map

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A researcher must see which claims share evidence despite a flat list hides dependencies, because one weak source can support too much; the story resolves when overloaded sources become obvious.

## Story spine

- Setup: a reference wall
- Inciting change: The list changes state before the objective is secure.
- Objective: see which claims share evidence
- Obstacle: a flat list hides dependencies
- Stakes: one weak source can support too much
- Action: notice the list → connects each claim to dated evidence → inspect the graph links
- Proof: graph links
- Limitation: A map visualizes lineage; it does not verify truth.
- Payoff: overloaded sources become obvious
