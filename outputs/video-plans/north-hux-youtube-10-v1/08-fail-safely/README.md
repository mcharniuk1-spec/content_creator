# 08. Watch the Agent Fail Safely

## Spoken script

This agent just sent the wrong price. Do not hide the failure. Freeze the workflow. Trace the input, model decision, tool call, and evidence it used. Revoke the action, restore the last good state, and route the case to a human. Now save the failure as a permanent evaluation case. Reliable agents are not failure-free. They are recoverable.
