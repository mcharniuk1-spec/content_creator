# ST-006 — The Rebuilt Handoff

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A project manager must restore missing context despite the last owner left only a vague note, because the next person could repeat the work; the story resolves when the successor can act without guessing.

## Story spine

- Setup: a handoff table
- Inciting change: The envelope changes state before the objective is secure.
- Objective: restore missing context
- Obstacle: the last owner left only a vague note
- Stakes: the next person could repeat the work
- Action: notice the envelope → rewinds from the clean handoff to the missing fields → inspect the handoff checklist
- Proof: handoff checklist
- Limitation: A checklist cannot replace domain judgment.
- Payoff: the successor can act without guessing
