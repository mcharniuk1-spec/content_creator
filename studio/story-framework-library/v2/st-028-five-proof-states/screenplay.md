# ST-028 — Five Proof States

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

An evidence analyst must separate fact from uncertainty despite all statements share one visual style, because viewers may treat hypotheses as facts; the story resolves when the claim state is visible.

## Story spine

- Setup: a classification desk
- Inciting change: The label set changes state before the objective is secure.
- Objective: separate fact from uncertainty
- Obstacle: all statements share one visual style
- Stakes: viewers may treat hypotheses as facts
- Action: notice the label set → assigns FACT, INTERPRETATION, HYPOTHESIS, and GAP → inspect the evidence key
- Proof: evidence key
- Limitation: Labels do not improve weak evidence by themselves.
- Payoff: the claim state is visible
