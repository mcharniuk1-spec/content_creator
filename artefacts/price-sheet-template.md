# Price sheet: the only place a price comes from

The model never writes a price. It reads this sheet and picks a line. The worst it can do is pick the wrong line, which you will see in the draft. It can never invent a number.

| code | service / item | unit | price | includes | not included | notes / when to ask a human |

| S01 | Service call, first hour | hour | | travel within 20 km | parts | after 18:00 use S01-E |
| S01-E | Service call, evening | hour | | | | |
| P01 | Deep clean, 2-bed | job | | supplies | inside oven | stairs above 3rd floor: +P09 |
| … | | | | | | |
| Q00 | Anything not on this sheet | | ASK | | | the draft must say "I'll confirm the price" |

Rules written on the sheet:
1. Owner and date at the top. Only the owner changes numbers.
2. Every draft quote quotes the code, so you can check it in two seconds.
3. Deposit and no-show policy printed at the bottom; the draft includes it every time.
4. If the customer describes something not on the sheet, the draft says the price will be confirmed. Never a guess.
