# ST-025 — Compass Before Speed

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A project lead must choose the next useful action despite the team accelerates before agreeing direction, because effort could compound in the wrong lane; the story resolves when speed follows a visible route.

## Story spine

- Setup: a route-planning table
- Inciting change: The compass changes state before the objective is secure.
- Objective: choose the next useful action
- Obstacle: the team accelerates before agreeing direction
- Stakes: effort could compound in the wrong lane
- Action: notice the compass → sets direction and stop conditions before moving → inspect the decision criteria
- Proof: decision criteria
- Limitation: The compass stands for criteria, not certainty.
- Payoff: speed follows a visible route
