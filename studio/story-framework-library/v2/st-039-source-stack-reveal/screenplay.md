# ST-039 — Source Stack Reveal

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A policy writer must support a rule with independent parents despite one secondary summary dominates the draft, because the rule may inherit its errors; the story resolves when the claim shows its evidence depth.

## Story spine

- Setup: a source shelf
- Inciting change: The book stack changes state before the objective is secure.
- Objective: support a rule with independent parents
- Obstacle: one secondary summary dominates the draft
- Stakes: the rule may inherit its errors
- Action: notice the book stack → reveals primary parents behind the summary → inspect the primary sources
- Proof: primary sources
- Limitation: Agreement among sources is not causal proof.
- Payoff: the claim shows its evidence depth
