# ST-015 — The Broken Source Link

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A fact checker must verify a factual sentence despite the source pointer ends at a search snippet, because the claim cannot be audited; the story resolves when the sentence gains a direct parent.

## Story spine

- Setup: a browser-free evidence desk
- Inciting change: The broken chain changes state before the objective is secure.
- Objective: verify a factual sentence
- Obstacle: the source pointer ends at a search snippet
- Stakes: the claim cannot be audited
- Action: notice the broken chain → traces the snippet to the original page → inspect the canonical URL
- Proof: canonical URL
- Limitation: Access today does not guarantee future availability.
- Payoff: the sentence gains a direct parent
