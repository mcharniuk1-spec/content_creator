# M2 knowledge routing

Start with `../docs/m2-three-stage-reconciliation.md` for the current owner-directed audience, English-only evidence policy and three-stage flow. Then read `m2-positioning.md`, `m2-operating-memory.md` and `m2-validation-lessons.md` with their dates and limitations.

Raw transcripts, frames, metrics snapshots and private database exports belong in source storage and versioned run artifacts. They are not automatically promoted into durable memory. Current language detection is probabilistic; old report counts are not a merged server receipt.

Historical YouTube knowledge is summarized in `../docs/m2-legacy-knowledge-summary.md` and excluded from the active Reel trace. Generation uses the disabled fal route described in `../docs/m2-fal-integration.md`. Shared deployment remains deferred pending the executor plan's acceptance tests.
