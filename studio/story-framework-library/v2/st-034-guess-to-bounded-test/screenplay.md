# ST-034 — Guess to Bounded Test

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A growth planner must turn a creative opinion into a test despite the team argues from taste, because production time can be wasted; the story resolves when the hypothesis becomes falsifiable.

## Story spine

- Setup: an experiment board
- Inciting change: The dice changes state before the objective is secure.
- Objective: turn a creative opinion into a test
- Obstacle: the team argues from taste
- Stakes: production time can be wasted
- Action: notice the dice → defines one variable and one decision rule → inspect the test card
- Proof: test card
- Limitation: A small test may not generalize.
- Payoff: the hypothesis becomes falsifiable
