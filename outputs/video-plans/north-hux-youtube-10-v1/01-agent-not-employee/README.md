# 01. Your AI Agent Is Not an Employee

## Spoken script

Your AI agent is not an employee. It is a workflow that can read, decide, and sometimes act. If you cannot name its inputs, tools, and authority, you do not have an agent. You have an unbounded risk. Give it a contract: allowed data, allowed actions, required evidence, and a human stop. Then test failure before you test scale. Reliable agents are bounded, observable, and recoverable.
