Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A reel editor must create rhythm without confusion despite every beat uses the same shot scale, because attention resets become predictable; the story resolves when each scale reveals new information.

## Story spine

- Setup: a cut timeline
- Inciting change: The clapper changes state before the objective is secure.
- Objective: create rhythm without confusion
- Obstacle: every beat uses the same shot scale
- Stakes: attention resets become predictable
- Action: notice the clapper → moves wide, medium, macro, then return → inspect the shot ladder
- Proof: shot ladder
- Limitation: Shot variety is not a retention guarantee.
- Payoff: each scale reveals new information
