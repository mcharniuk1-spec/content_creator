Weekly niche radar for the M2 Lab Instagram account. It watches what works in the niche around putting AI into business processes, and turns that into specific shooting cards.

> One line: the machine counts and narrows, people read and decide.

## How a week runs

The intended server schedule is Monday and Thursday. This local run did not inspect or deploy the server scheduler. The updated default server entry replays existing data; live HikerAPI collection requires the separately approved server pilot and activation.

| Step | Who | Cost |
|---|---|---|
| Pull reels across the account set | machine | ~$2 per run |
| Score each reel against its own author's norm | machine | free |
| Download the top of the window, cut frames, transcribe speech | machine | free |
| Split the transcript into hook / body / ending | machine | free |
| Tag topics, build the statistics | machine | free |
| Compare with the last snapshot — what moved | machine | free |
| Write the angle, hook and shot plan for each card | agent, from our positioning | free — runs on the subscription |
| Read the cards, comment, take some into production | **Misha and Max** | 20 minutes |

## What lands here

Cards — one row per suggested reel, with the contact sheet, the transcript by block, the angle and the three shooting columns. This is what you work with.

Reels — every reel in the window with everything collected and everything derived: metrics, score and its components, length, cuts, words per block, speaking pace, caption and hook devices, topics. This is what the picks are made from.

Accounts — every account in the set: profile, how it performs, what it does consistently, and our call on what to borrow from it.
