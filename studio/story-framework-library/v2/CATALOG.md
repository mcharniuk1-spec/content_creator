## How to read one package

Start with `contact-sheet.svg`, then read the six frame SVGs left-to-right. Use `screenplay.md` for narration and cut logic, `prompt.md` for future provider/footage replacement, `story.json` for automation, and `report.md` for truth/rights boundaries.
