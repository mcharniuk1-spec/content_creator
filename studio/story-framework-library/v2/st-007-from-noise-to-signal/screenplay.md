# ST-007 — From Noise to Signal

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A market researcher must identify one reusable pattern despite popularity signals are mixed with evidence, because a trend claim could be overstated; the story resolves when one pattern survives with caveats.

## Story spine

- Setup: a wall of clippings
- Inciting change: The funnel changes state before the objective is secure.
- Objective: identify one reusable pattern
- Obstacle: popularity signals are mixed with evidence
- Stakes: a trend claim could be overstated
- Action: notice the funnel → separates observation from inference → inspect the evidence labels
- Proof: evidence labels
- Limitation: A reference pattern is not performance proof.
- Payoff: one pattern survives with caveats
