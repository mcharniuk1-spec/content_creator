# ST-018 — The Missing Owner

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A program coordinator must move one decision forward despite every task has a date but no owner, because the deadline can pass without action; the story resolves when the next action has a visible owner.

## Story spine

- Setup: a planning wall
- Inciting change: The name tag changes state before the objective is secure.
- Objective: move one decision forward
- Obstacle: every task has a date but no owner
- Stakes: the deadline can pass without action
- Action: notice the name tag → adds one accountable role and review point → inspect the ownership card
- Proof: ownership card
- Limitation: Ownership labels do not guarantee completion.
- Payoff: the next action has a visible owner
