# V3 Realistic Storyboard Catalog

Fifty original six-shot photorealistic previsualization packages derived from the v2 causal stories.

Each folder contains `prompt.txt`, frozen `source-story.json`, `generation.json`, `contact-sheet-generated.png`, compact `contact-sheet-final.png`, and six ordered 540×960 images in `frames/`. Read `F01` through `F06` in order. These are reference stills—not final video, source reconstructions, creator imitations, or performance evidence. `manifest.json` is the machine receipt.
