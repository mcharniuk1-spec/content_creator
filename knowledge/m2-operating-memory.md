# M2 operating memory

FACT: Instagram Reels is the active research platform. YouTube is concluded and archive-only. Signal owns immutable observations, eligibility, separate evidence modalities, descriptive comparison and independent release review. Studio owns original scripts, timed scene plans, original footage binding, optional exact approved generation, deterministic composition and production QA.

FACT: A missing save counter is not zero. Date-only snapshots with unequal exposure are descriptive. Higher engagement does not prove why a video worked. Cut counts are not shots, semantic scenes or extracted frames. Empty ASR output does not prove silence.

INTERPRETATION: Use the smallest independently reviewed evidence capsule for each specialist stage. Preserve the raw source run locally; promote reviewed methods and corrected assumptions only. Text-derived script hypotheses may proceed as original drafts with sparse-source limitations, while final Best-Reel acceptance remains blocked.

HYPOTHESIS: Local SQLite checkpoints and immutable files provide an adequate starting controller for manual and partner-server runs. A service deployment must bind actor identities to its own authentication and enforce file permissions; actor labels alone are not authentication.

GAP: Live HikerAPI response/billing validation belongs to an exact approved server pilot. Paid video generation requires an exact prompt/frame/rights digest, provider authentication, a dated tariff, and owner budget. Synthetic fixture tests and Remotion previews do not prove provider quality, competitor media coverage or production readiness.

Use [[m2-positioning]] for the audience and perspective. The executable contract lives in `docs/m2-system-architecture.md`, `docs/m2-operator-guide.md`, `agents/m2-roles.json` and the role skills. Every new source snapshot, changed policy or changed executable implementation requires a new run identity; do not mutate a frozen release.
