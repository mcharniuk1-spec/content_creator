# ArchFlow Content Engine — Agent Contract

This folder is a separate ArchFlow-aligned content-research and previsualization project. When it is nested inside ArchFlow, read the parent ArchFlow `AGENTS.md` first; in a standalone public clone, this contract and `docs/handoff/current-public-handoff.md` are the starting boundary.

## Current phase

Phase 1 is provider-disabled and read-only with respect to external systems. It may research approved public sources, normalize evidence, prepare 10–15 original content plans, create local frame-by-frame storyboard assets, prepare contact sheets and PDF reports, and prepare a Figma delivery package. It may not generate final video, call paid media providers, install or clone dependencies, log into social networks, mutate Figma, publish, deploy, push Git, use private media, or synthesize a real person's voice or likeness without a new exact approval.

The current North Hux implementation contract is routed through `docs/full-system-blueprint.md`, `docs/database-backup-restore.md`, `docs/repository-setup.md`, and `knowledge/obsidian-wikillm-setup.md`. Run `20260826-youtube-video-census-10k-v1` is terminally frozen at `PASS_WITH_LIMITATIONS`; read its `agent-handout.md`, `operator-guide.md`, and `terminal-receipt.json` before continuation, and create a new run ID instead of mutating its evidence. The 10K YouTube corpus is a broad screen; never call it 10K qualified competitors. Collection completeness uses 10,000, while strategy uses the explicit 2,949-video analysis-eligible denominator. Transcript, frame, comment, and native-Short proof remain separate denominators.

## Mandatory order

1. Inspect this folder and the latest `runs/*/agent-handout.md`.
2. Read `README.md`, `docs/architecture.md`, `docs/role-hierarchy.md`, `docs/research-and-analysis-contract.md`, `docs/tool-fit-and-boundaries.md`, `docs/previsualization-and-figma.md`, and `docs/media-production-boundary.md`.
3. Run or recover a machine-emitted, provider-disabled architecture admission receipt before implementation or sub-agent dispatch. If the launcher does not exist yet, use only the bounded bootstrap phase defined in `HANDOFF_PROMPT.md` to create it and its tests.
4. Run `agent-reach doctor --json`. Use only each channel's reported `active_backend`. Record unavailable channels as `GAP` or `BLOCKED`; never log in, import browser cookies, or install a backend without approval.
5. Create a bounded `ResearchBrief`, task contracts, source allowlist, rights state, and output schemas before collecting material.
6. Register every source and material in the ledgers before analysis.
7. Separate FACT, INTERPRETATION, HYPOTHESIS, and GAP.
8. Require maker/reviewer separation and owner gates at Figma mutation, provider generation, voice/likeness, publishing, deployment, and external writeback.
9. Save a durable run handout and focused validation results before claiming completion.

## Knowledge and retrieval

- `knowledge/index.md` routes to bounded context.
- `knowledge/memory.md` stores independently promoted reusable facts and constraints only.
- `knowledge/insights.md` stores reviewed cross-run interpretations only.
- Raw research, transcripts, screenshots, prompts, and media stay run-local and are not automatically memory.
- Use lexical search first. LlamaIndex may index only an explicit allowlist with source paths. A vector backend is optional and requires a benchmark and approval.
- Graphify may cover only this folder's routing files, docs, schemas, configs, knowledge, and run handouts. Never point it at all of ArchFlow, Documents, or the home directory.
- Obsidian/Nexus is optional. Do not create or mutate a vault unless the owner separately approves the exact vault and target notes.

## External tool boundaries

- Agent Reach is a capability router, not proof that every network is reachable.
- Sherlock is only for approved public brand/product username discovery. It is not a trend engine and must not build personal dossiers or deanonymize prospects.
- OpenMontage is a candidate production-planning/editing integration. Its AGPL license and dependency footprint require review before reuse or installation.
- Open-Generative-AI is an optional provider/model exploration surface, never the policy core. Do not inherit an unrestricted or no-filter posture.
- GPT Image in Codex may create approved storyboard stills during an explicitly authorized visual-generation run. Application automation requires a separately approved API adapter.
- Figma work starts with `whoami`. Continue only when the authenticated identity exactly matches the owner-specified account in the private handoff. Creating pages, frames, or files is an external mutation and requires exact owner approval.

## Hard stops

Stop and ask the owner before any dependency install or clone, credential entry, logged-in source access, browser-cookie reuse, API call that transmits data or incurs cost, Figma mutation, private-video ingestion, voice or likeness work, publishing, scheduling, social engagement, deployment, Git remote write, or destructive operation.

Never claim trend coverage, connector readiness, performance, reach, demand, ROI, or production status without a dated receipt and direct evidence.
