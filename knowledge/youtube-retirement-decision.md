## Decision

The historical YouTube research run is frozen and excluded from the active M2Lab Content Engine plan. Do not continue YouTube collection, transcript analysis, creator ranking, topic analysis, scene analysis, or recommendation work in the current system.

The archive may contribute only source-agnostic reliability methods: immutable evidence, explicit denominators, typed gaps, maker/reviewer separation, source rights, restore receipts, and honest distinction between collection and analysis coverage. It may not contribute current Instagram market claims, active creators, performance thresholds, script premises, or examples to copy.

## Enforcement

- Active platform registry contains only `instagram_reels`.
- Current run config sets `youtube_active_research=false`.
- Current Signal-to-Studio and ScriptCard v2 contracts require Instagram Reels and exclude YouTube lineage.
- Legacy multi-platform schemas are `compatibility_only` or `frozen_fixture` in the schema lifecycle registry.
- A future revival requires a new explicit owner decision, new admission, new run ID, fresh evidence/rights review, and a new active schema/config release.

No historical file is deleted or mutated by this decision.
