# avatar

1080x1080, placement `avatar`. Profile picture, circle cropped by Instagram to r 486
at (540, 540).

| Slot | What it takes |
|---|---|
| `mark` | `on` places the mark. Empty leaves the surface bare. |
| `surface` | `light` (Paper, colour mark, the primary version) or `dark` (Ink, mono Paper mark). Control slot, no box. |

Geometry: mark 620 px centred, box corners 438 from the centre, well inside the r 486
inset circle. 620 is 57 percent of the crop diameter, inside the 55 to 60 percent
recommendation for legibility at the small displayed sizes (32 to 150 px, disputed).

Which mark on which surface is not a choice made here: the colour mark's silhouette is
Ink, so on an Ink surface it disappears. The dark example therefore uses the mono Paper
mark, and `surface` switches it automatically.

This template supersedes `source/avatar-final-2026-09-01.png` (1 Sep), which was built
on a different palette. Render `paper-color` and upload that as the profile picture.
