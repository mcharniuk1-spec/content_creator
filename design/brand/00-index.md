# M2 Lab brand book: content

Load one file at a time. Each is self-contained.

| File | Load it when |
|---|---|
| `01-positioning.md` | Writing the promise, a bio, an about section, or an offer. Checking whether a claim is allowed. Deciding language or geography wording. |
| `02-audience.md` | Choosing a topic, judging whether a piece is too technical, writing to a specific reader, or answering "so what do I do next". |
| `03-personality.md` | Deciding how a piece should feel, checking that a script sounds like us, or checking the Human face + real proof + verdict formula. |
| `04-voice.md` | Writing or editing any actual sentence: hook, voice-over, caption, slide, reply, disclosure. Stating a verdict, a number, a failure or a closing line. |
| `05-vocabulary.md` | Running the copy linter, choosing wording, or spelling a brand or format name. |
| `06-formats.md` | Planning the week, structuring a Reel, applying the editorial filter, or checking cadence and verdict requirements. |

Visual identity, color, type and layout live outside this folder.
