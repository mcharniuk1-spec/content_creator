# ST-031 — Inbox to Ordered Queue

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

An operations coordinator must turn chaotic requests into controlled work despite messages arrive without priority or owner, because urgent work can disappear; the story resolves when the queue can be reviewed at a glance.

## Story spine

- Setup: a digital intake wall
- Inciting change: The inbox changes state before the objective is secure.
- Objective: turn chaotic requests into controlled work
- Obstacle: messages arrive without priority or owner
- Stakes: urgent work can disappear
- Action: notice the inbox → classifies urgency, owner, and next state → inspect the routing rules
- Proof: routing rules
- Limitation: Routing quality depends on declared criteria.
- Payoff: the queue can be reviewed at a glance
