# ST-042 — Faster Tool, Slower Workflow

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A team operator must finish a repeatable task despite every step uses a different fast tool, because handoffs consume the saved time; the story resolves when the workflow loses unnecessary handoffs.

## Story spine

- Setup: a tool-switching desk
- Inciting change: The stopwatch changes state before the objective is secure.
- Objective: finish a repeatable task
- Obstacle: every step uses a different fast tool
- Stakes: handoffs consume the saved time
- Action: notice the stopwatch → counts transitions instead of tool speed → inspect the handoff map
- Proof: handoff map
- Limitation: This is a process hypothesis until measured.
- Payoff: the workflow loses unnecessary handoffs
