# ST-019 — Upload Without Redaction

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A research assistant must prepare a public analysis sample despite a raw file still contains private fields, because private data could leave its boundary; the story resolves when only the bounded sample proceeds.

## Story spine

- Setup: a safe intake desk
- Inciting change: The shield changes state before the objective is secure.
- Objective: prepare a public analysis sample
- Obstacle: a raw file still contains private fields
- Stakes: private data could leave its boundary
- Action: notice the shield → stops the upload and masks restricted fields → inspect the redaction receipt
- Proof: redaction receipt
- Limitation: Redaction must be independently checked.
- Payoff: only the bounded sample proceeds
