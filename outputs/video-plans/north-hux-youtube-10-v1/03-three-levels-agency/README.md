## Spoken script

The same workflow can contain three different levels of agency. An assistant drafts. A copilot recommends. A delegated agent executes inside a boundary. Use the same customer request and change only decision authority. Drafting is easy to reverse. Recommendations need evidence. Execution needs permissions, limits, and rollback. Do not buy the most autonomous option by default. Choose the lowest agency level that produces the business result.
