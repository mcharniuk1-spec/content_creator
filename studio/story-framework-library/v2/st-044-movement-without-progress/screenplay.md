# ST-044 — Movement Without Progress

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A program manager must advance one outcome despite many cards move but no decision closes, because activity can mask stalled value; the story resolves when progress becomes a changed state.

## Story spine

- Setup: a task board
- Inciting change: The moving cards changes state before the objective is secure.
- Objective: advance one outcome
- Obstacle: many cards move but no decision closes
- Stakes: activity can mask stalled value
- Action: notice the moving cards → tracks the outcome instead of card motion → inspect the outcome marker
- Proof: outcome marker
- Limitation: One outcome may still depend on external actors.
- Payoff: progress becomes a changed state
