# ST-035 — Cluttered Frame to One Action

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A visual educator must make the next action obvious despite captions, UI, charts, and face compete, because the viewer cannot locate the focal point; the story resolves when one action dominates each beat.

## Story spine

- Setup: a vertical canvas
- Inciting change: The layers changes state before the objective is secure.
- Objective: make the next action obvious
- Obstacle: captions, UI, charts, and face compete
- Stakes: the viewer cannot locate the focal point
- Action: notice the layers → stages layers in causal order → inspect the focus ring
- Proof: focus ring
- Limitation: Accessibility and platform safe zones still need QA.
- Payoff: one action dominates each beat
