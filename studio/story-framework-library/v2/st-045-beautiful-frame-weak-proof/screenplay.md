# ST-045 — Beautiful Frame, Weak Proof

Truth state: `ORIGINAL_LOCAL_PREVISUALIZATION / EXTERNAL_PROVIDER_NOT_RUN`

## Logline

A creative director must make an explanation trustworthy despite visual polish hides a missing source, because the audience may remember style as certainty; the story resolves when clarity replaces borrowed authority.

## Story spine

- Setup: a polished storyboard
- Inciting change: The sparkle changes state before the objective is secure.
- Objective: make an explanation trustworthy
- Obstacle: visual polish hides a missing source
- Stakes: the audience may remember style as certainty
- Action: notice the sparkle → reduces decoration and exposes the evidence state → inspect the evidence label
- Proof: evidence label
- Limitation: A plain frame is not automatically accurate.
- Payoff: clarity replaces borrowed authority
